# Data model

All types and tables live in `src/lib/db.ts`. Database name: **`bms_db_v1`**.
IDs are strings generated by `uid()` (timestamp base36 + random suffix).
All dates/timestamps are epoch milliseconds.

## Versions & migration

**v1 stores**

```
companySettings  id
customers        id, name, createdAt
suppliers        id, name, createdAt
categories       id, name
products         id, name, categoryId, createdAt
quotations       id, number, date, customerId, createdAt
invoices         id, number, date, customerId, status, createdAt
receipts         id, number, date, customerId, invoiceId, createdAt
purchases        id, number, date, supplierId, createdAt
```

**v2 stores (additive — existing data is preserved)**

```
sizes               id, label, createdAt
termsTemplates      id, name, createdAt
generalInfoTemplates id, name, createdAt
techSpecTemplates   id, name, kind, createdAt
bankAccounts        id, bankName, createdAt
quotationTemplates  id, name, createdAt
```

New fields added to existing types are all optional, so older records keep
working without a data rewrite.

## Core entities

**CompanySettings** (`id: "singleton"`) — name, logo (data URL), address,
mobile, altMobile, email, website, gstin, pan, cin, bank fields, upiId, terms,
declaration, authorizedSignatory, signature, stamp, currency + symbol,
document prefixes (`invoicePrefix`, `quotationPrefix`, `receiptPrefix`,
`purchasePrefix`) and next numbers. `getCompany()` seeds `DEFAULT_COMPANY` on
first run; `nextNumber(kind)` returns e.g. `QT-0007` and increments the counter.

Only **logo, name, address and phone** are printed on documents — by design, so
headers stay clean.

**Customer / Supplier** — name, company, mobile, email, gstin, address (+ city,
state, pincode for customers), `openingBalance`, `createdAt`.

**Category** — name.

**Product** — name, sku, categoryId, unit, hsn, gstRate, purchasePrice,
sellingPrice, openingStock, currentStock, reorderLevel, description,
`specifications`, `defaultSizes[]`.

**LineItem** (embedded in documents) — productId, name, hsn, `size`,
`description`, quantity, unit, rate, discountPct, gstRate and the computed
`taxable`, `gstAmount`, `total`.

**ExtraCharge** — `{ label, amount }` (transportation, installation, unloading,
misc…).

**Quotation** — number, date, `validity`, `preparedBy`, `siteLocation`,
`contactPerson/Phone/Email`, customerId + `customerSnapshot`, items, subtotal,
discountTotal, gstTotal, `extraCharges[]` + `extraChargesTotal`, roundOff,
grandTotal, notes, terms, status (`draft | sent | accepted | converted |
rejected`), plus **snapshots** taken at save time:
`generalInfoSnapshot`, `techSpecSnapshot`, `electricalSnapshot`,
`termsSnapshot`, `bankSnapshot`, `templateId`, and the source template IDs.
Snapshots mean editing a master later never rewrites history.

**Invoice** — number, date, dueDate, customer + snapshot, billing/shipping
address, items, subtotal, discountTotal, cgst/sgst/igst/gstTotal, roundOff,
grandTotal, amountPaid, balance, `isIgst`, notes, terms,
status (`unpaid | partial | paid`).

**Receipt** — number, date, customerId, optional invoiceId, amount,
mode (`cash | bank | upi | cheque | other`), reference, notes.

**Purchase** — number, date, supplierId + snapshot, items, totals, amountPaid,
balance, status.

## Quotation masters (v2)

| Type | Shape | Use |
| --- | --- | --- |
| `SizePreset` | `{ label }` | reusable sizes in the item editor |
| `TermsTemplate` | `{ name, isDefault, terms: [{ id, text, enabled }] }` | reorderable, individually toggleable terms |
| `GeneralInfoTemplate` | `{ name, isDefault, fields: [{ key, label, value }] }` | configuration, transportation, foundation, roof, wiring… |
| `TechSpecTemplate` | `{ name, kind: "technical" \| "electrical", isDefault, sections: [{ title, rows: [{ label, value }] }] }` | frame, panel, roof, floor, doors, electricals… |

## Calculations (`src/lib/calc.ts`)

```
gross    = quantity × rate
discount = gross × discountPct / 100
taxable  = gross − discount
gst      = taxable × gstRate / 100
line     = taxable + gst
```

`computeTotals(items, isIgst)` sums subtotal / discount / GST, splits GST into
CGST+SGST (or IGST), rounds the grand total to the nearest rupee and records the
`roundOff` difference. `applyStockDelta(items, ±1)` adjusts `currentStock`
inside a read-write transaction.

## Formatting (`src/lib/format.ts`)

Indian-locale money (`formatMoney`), numbers, `dd/mm/yyyy` dates, date-input
converters, and `numberToWordsIndian()` for the amount-in-words line
(crore / lakh / thousand with paise).
